# Business Questions

## Employer Migration

### Which active employers should be migrated?

The employer extraction identifies active organizations with recent business activity to support migration planning.

### Who is the primary business contact?

The query identifies a single primary administrator for each organization.

## Job Order Migration

### Which active job orders should be migrated?

The extraction includes only active positions meeting reporting requirements.

### What application methods are available?

Application methods are translated into reporting-friendly values.

### What compensation type should be reported?

Salary frequency codes are converted into business-readable categories.

### What benefits are associated with each job?

Benefits are aggregated into reporting-ready fields.

### How can job-order reporting be standardized?

Classification codes are reformatted into a consistent structure.
